01
PAIN POINTS

Excel 管不動、SaaS 套不準的時候

PAIN POINTS

預算這件事跨年、跨單位、跨類別、跨人，Excel 撐不住、套裝 SaaS 又貼不上你獨特的組織結構。最後變成「預算規劃靠 Excel、執行靠記憶、檢核靠補單」。

現在：Excel 加記憶加補單
  • 業務費要分 12 個月、設備費也要分，改一次就 Save As V3、V4、V5，到底哪個是最終版沒人知道
  • 主管口頭同意「材料費借調 50 萬到設備費」，流用了沒寫清楚，年底結算就對不起來
  • 到底現在花了多少、預估能不能達標，要等財務月報才知道，發現太低都來不及加速採購
  • 新年度開始去年架構全部要重建一次，又沒有權限機制，等於全公司資料互相開放
用了 Budget System
  • 月份分配、子類別、版本快照都在系統裡，沒有滿天飛的 Excel 版本
  • 流用走系統紀錄，每筆都有來源去向，杜絕灰色地帶
  • 執行率即時儀表板，哪個計畫快超支、哪個太慢花一目了然
  • 一鍵跨年複製去年架構、4 種角色權限隔離，跨單位資料天然分開

ARCHITECTURE

前後端分離，內網一台主機跑得起來

SYSTEM ARCHITECTURE

基於開源主流框架，無雲端依賴。所有資料、後端服務、前端 SPA、資料庫均部署在貴司內網一台主機，搭配 IIS 反代提供使用者瀏覽器存取。

┌─ Frontend (SPA) │ React 18 + Ant Design 5 + Recharts + @dnd-kit │ → build 後輸出 dist/ 靜態檔，由 IIS 直接提供 │ ├─ Reverse Proxy │ IIS 10 + URL Rewrite + ARR │ → /api/* 反代到 backend；其餘路徑 SPA fallback │ ├─ Backend (REST API) │ Node.js 20 + Express + JWT + bcryptjs │ node-cron 排程 / nodemailer 通知 / ExcelJS 匯出 │ → 由 NSSM 註冊為 Windows 服務開機自啟 │ └─ Database MySQL 8.0（portable，安裝包內附） → 純資料層，可選改用既有的 SQL Server / PostgreSQL

05
PROCESS

5 個階段，從訪談到上線

IMPLEMENTATION FLOW
STEP 01

需求訪談

1-2 次線上 / 到府訪談，盤點組織結構、預算流程、簽核習慣、現有資料來源。輸出客製需求書。

STEP 02

客製組態 + 開發

依訪談結果調整資料結構、UI 標籤、流程階段、權限矩陣、報表欄位。預計 2-6 週（視客製深度）。

STEP 03

資料移轉

協助匯入舊 Excel / 舊系統的歷史預算與採購資料。提供 CSV / SQL 匯入工具，第一輪資料正確性對帳。

STEP 04

上線部署 + 教育訓練

到府或遠端部署到貴司內網主機，建立 IIS / 防火牆 / 服務。各角色 1.5-2 小時操作教育訓練。

STEP 05

維護期支援

3-12 個月維護期（依方案），含問題排除、調整微調、版本升級。期滿可續約。

FAQ

常見問題

FREQUENTLY ASKED
Q.01
跟現成 SaaS 預算系統有什麼不同？
現成 SaaS 的組織命名、流程階段、報表欄位多半得遷就它既定的樣式；我們則是依貴司的組織單位與簽核流程現況來設計。代價是建置時間較長（約 4-8 週，SaaS 開帳號就能用），但能省去長期「人去配合系統」的隱形成本。
Q.02
系統會放在我們公司內網嗎？資料安全如何？
是的，整套部署在貴司內網一台主機（或 VM）。前端 SPA、後端 API、MySQL 資料庫全部本機執行，無雲端依賴。日常運作不需要對外網路，瀏覽器透過內網或 VPN 存取。資料庫備份、權限管理由貴司 IT 掌握。
Q.03
可以接我們既有的 HR / ERP 系統嗎？
可以。屬於企業全客製範圍。常見介接：HR 系統同步員工資料、ERP 拉預算與實際支出、採購系統推送決標結果。介接方式以 REST API 或 SQL view 為主，視貴司既有系統而定。
Q.04
建置完成後，未來我們想自己加功能可以嗎？
可以。我們交付完整原始碼（前端 + 後端 + DB schema + 部署腳本），不綁授權、不藏關鍵程式。貴司若有 Node.js / React 工程師可自行擴充。我們也可在維護合約內持續開發。
Q.05
多少人可以同時使用？需要按帳號數加價嗎？
不需要。系統部署在貴司內網一台主機，使用人數無限制（受限於該主機效能）。實測一台中階伺服器可支撐 50-100 位使用者同時存取無壓力。
Q.06
需要哪種伺服器規格？
Windows Server 2019 / 2022（或 Windows 10/11 Pro 也可）、4 核心 CPU、8GB RAM、100GB 硬碟即可起步。Ubuntu / RedHat 也支援，但需另議部署腳本（既有為 Windows 一鍵包）。
Q.07
導入週期通常多久？
標準版約 4-6 週、進階版 6-10 週、全客製 8-16 週。以「需求訪談 → 客製開發 → 內測 → 教育訓練 → 上線」五階段切，每階段都有里程碑驗收。
Q.08
付款方式？
分三期：簽約 30%（啟動）/ 內測完成 40%（功能交付）/ 上線驗收 30%。可開立發票、可接公司對公司付款。簽約後到上線約 1.5-3 個月。
