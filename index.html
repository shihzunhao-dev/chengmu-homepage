GENERAL NOTES

澄沐實業是一間登記在台灣的軟體事務所，工程師主導、專案精實。沒有「敏捷團隊」、沒有「Scrum Master」，也不打算融資擴張。我們只寫交付後還能放心用很多年的程式碼。

服務客戶橫跨核能、電力、光電與一般中小企業。從 ASP.NET Web Forms 老站翻新，到 FastAPI + React 新站從零開始，再到自有產品上架販售。從訪談、開發到部署都由內部完成，沒有外包、沒有層層轉手。

如果你的專案沒人想接、文件不全、規格還沒定，但你已經知道「現在這套不能繼續用」，我們大概聊得起來。

FAQ

常見問題

FREQUENTLY ASKED
Q.01
一個客製專案大概要多久？
看範圍。一個內部報表工具大概 2 到 3 週、一套完整的工單簽核系統 2 到 4 個月、舊系統翻新加新功能 3 到 6 個月。我們會在訪談後給明確的時程與里程碑，不灌水也不畫大餅。
Q.02
可以只買 PCC Tender Watch，不接客製案嗎？
可以。自有產品（PCC Tender Watch、家庭存摺、預算系統）都是獨立販售，不綁客製專案。買了之後不滿意，14 天內可遠端鎖序號退費，沒有長期合約。
Q.03
為什麼產品堅持買斷不做訂閱？
一個工具值不值得做的標準，是它在你忘了我們公司還在不在的十年後，仍然能用。訂閱會讓你被軟體公司綁架，買斷則把控制權還給你。我們的產品都設計成可純本機運作，伺服器關掉了照樣能跑。
Q.04
支援哪些產業？非核能電力光電的中小企業可以接嗎？
可以。我們最熟核能、電力、光電產業的內部流程（工單、簽核、報表、LDAP 整合、廠房資料庫），但客製專案本身不限產業，一般中小企業的 ERP 整合、預算管理、報表自動化、舊網站翻新都接過。
Q.05
有套很舊的 ASP.NET Web Forms 系統，可以接手維護或現代化嗎？
可以，這是我們的主力之一。從 IIS 部署、SQL Server 舊資料庫遷移、報表 PDF/Excel 輸出，到逐步把前端抽換成 React、後端換成 FastAPI 的漸進式現代化都能做。沒人想接的、文件不全的、規格還沒定的，反而是我們擅長的案型。
Q.06
自有產品要連雲端嗎？資料會被傳出去嗎？
不需要連雲端、資料不會傳出去。三個自有產品都設計成可純本機或內網運作，病歷、預算、標案資料都留在你的電腦或公司主機，不經過第三方伺服器。授權驗證會做一次線上 HMAC 握手，握手完之後離線也能用。
