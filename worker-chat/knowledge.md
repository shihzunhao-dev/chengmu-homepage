## 公司簡介
- 公司名稱：澄沐實業有限公司（CHENGMU INDUSTRIAL CO., LTD.），位於台灣。
- 定位：工程師主導的專業資訊服務公司。需求訪談、開發、部署到日後維護，都由同一組工程師負責，不外包、不轉手。
- 交付原則：原始碼隨系統一起交付；系統以「交付後能長期穩定使用」為目標。
- 服務對象：各行各業。只要是需要把作業流程系統化、把資料整理清楚，或需要有人顧好既有系統的企業與單位，都是我們服務的對象。

## 服務一：客製化程式系統開發
依照客戶實際的作業流程，量身打造系統，從需求訪談、設計、開發到上線部署一次完成。

主要的系統類型：
- 營運管理系統：採購（請購、採購、驗收、請款、付款）、工單、請修、工作許可、定期保養、人員與權限管理。
- 倉儲管理系統：進出貨、庫存、儲位、盤點、供應商管理與評鑑。
- 資訊服務系統：內部入口網站、文件與公文管理、電子簽核、查詢平台、對外服務網站。
- 現場作業系統：手機或 Android 手持裝置（PDA）現場登錄，例如設備巡檢讀值，自動偵測異常並觸發分級簽核。
- 報表與文件產出：自動產出 Excel、PDF、Word 報表與表單，含趨勢圖、簽核欄與電子章。
- 業務管理工具：預算執行率管理、報價單管理等。
- 系統整合：不同系統之間的資料串接（API、資料庫同步）、排程自動化。

常用技術：
- 網頁系統：ASP.NET Web Forms（C#、VB.NET）、Python（Flask、FastAPI）、Node.js + React。
- 資料庫：SQL Server、MySQL、PostgreSQL、SQLite。
- 報表：Crystal Reports、RDLC、Excel／PDF／Word 程式化產出。
- 行動裝置：Android 現場作業 App、PWA（可安裝到手機的網頁應用）。
- 部署環境：Windows Server + IIS，或雲端服務。

## 服務二：程式系統維護
- 既有系統的除錯、功能增修、效能調整與版本升級。
- 接手文件不齊、原開發者已離開的舊系統：先閱讀程式碼，整理出系統架構與資料表說明，再規劃修改範圍。
- 舊系統資安補強，例如把字串拼接的 SQL 改成參數化查詢、補上權限檢查。
- 舊站搬遷到新的 Windows Server / IIS，或升級 .NET Framework 版本。
- 提供更新安裝包：含部署前檢查、一鍵套用與回復機制，降低上線風險。
- 維護方式可簽年度維護合約，也可以有需要時個案處理。

## 服務三：資訊專業服務
- 系統架構與技術選型諮詢：新系統該用什麼技術、舊系統要修還是重寫。
- 數據整理：資料清理、整合多個來源的資料、建立查詢與統計報表，讓散落在各處的資料能直接拿來用。
- 報表自動化：把每週人工整理的 Excel 改成自動產出。
- 伺服器與部署：IIS 站台設定、SSL 憑證、資料庫搬移與備份規劃。
- 可以單次諮詢，也可以搭配開發或維護一起進行。

## 合作流程
0. 線上需求整理（可選）：還沒有具體想法時，可以先在官網對話框由服務助理一題一題協助整理，最後產生一份需求摘要，工程師接手後以這份摘要為起點，不用從頭說明。
1. 需求訪談：了解現行作業流程與痛點。
2. 評估與報價：整理功能範圍、時程與費用，雙方確認後簽約。
3. 開發：分階段展示進度，邊做邊確認。
4. 測試與上線：在客戶環境部署並陪同上線。
5. 保固與維護：上線後的問題處理與後續增修。
